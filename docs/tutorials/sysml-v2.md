# Introduction to SysML v2

## Why SysML v2

SysML v2 replaces the XML-centric exchange model of earlier languages with a **textual notation**. That makes models:

- **Git-friendly** — diffs and merges work on readable source files
- **Agent-friendly** — AI tools can read and edit the same files humans use
- A practical **reference model** that several disciplines can share during development and maintenance

## Relation to UML and SysML v1

SysML grew from UML for systems engineering. SysML v1 reused UML diagrams and XMI. SysML v2 keeps systems concepts (parts, ports, requirements, use cases, views) but rebuilds the language on KerML with definition/usage and a standard textual form. Diagrams remain views of the model; the source of truth is the text.

## Why SysML Viewer

SysML Viewer is an open-source viewer and layout editor for SysML v2 models. It is prepared for both **documentation** and **MBSE** workflows: packages, requirements, use cases, logical and physical architecture, and dynamics diagrams can be opened, arranged, and saved as view layouts.
