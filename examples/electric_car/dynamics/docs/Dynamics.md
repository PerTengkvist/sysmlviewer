# Dynamics

Dynamics of the electric car. VehicleModes is the state machine every scenario moves through. Each occurrence def is one use case drawn as a sequence: an actor asks, a controller decides, actuators act, and the driver gets an acknowledgement (dashed «Reply» message). The lifelines are the parts of the occurrence: reference parts typed by the logical part defs of LogicalArchitecture::Types (and by the actor defs), named like the logical parts, so the sequences and the logical architecture read as one model. Messages are drawn in the order they are declared. Each occurrence def states the mode it starts in and the mode it ends in.
