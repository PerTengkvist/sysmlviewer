# maneuvrabilityControlSw

Software component for steering angle and directional control. Hosted on the maneuvrability computer. Implements the logical steering wheel.

Part of `maneuvrabilityEcu`.

## Relations

- Implements logical `steeringWheel`.

- `PhysicalTree`
