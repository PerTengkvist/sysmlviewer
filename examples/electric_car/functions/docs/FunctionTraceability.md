# FunctionTraceability

Traceability from the functions and their functional entities to the use cases they carry out. Each function «refine»s the use cases it realizes, so a use case's objective requirement is reached from the function, from its functional entities and from the logical parts those entities are allocated to. Drive and Park are composites and are reached through the use cases they include. TurnLeft and TurnRight are refined by both Maneuvrability (steering) and Lighting (direction indicators), and Brake by both SpeedControl (deceleration) and Lighting (brake lamps). Each functional entity also «refine»s the use cases it serves; together they cover exactly the use cases of their function, and a logical part climbs through the entity allocated to it to the use cases that entity serves.
