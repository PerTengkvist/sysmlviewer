# FunctionTraceability

Traceability from the functions to the use cases they carry out. The main form is a «refine» from a function step to the use case step it realizes: every system step of a use case is realized by one or more function steps, and a function step that reads an actor's input refines that actor's step. The function, its functional entities and the logical parts they are allocated to follow from those links, through ownership, perform and allocate. The explicit «refine»s from each function and each functional entity to its use cases, the form used before step links, are kept alongside; check_sysml reports any difference between them and the steps (explicit-mismatch). Drive and Park are composites and are reached through the use cases they include. Several use cases are realized by more than one function: TurnLeft and TurnRight by Maneuvrability (steering) and Lighting (indicators), Brake and EmergencyStop by SpeedControl (deceleration) and Lighting (brake lamps, hazard lights), and every use case that ends with an indication on the cluster also by DriverFeedback. A logical part climbs through the entity allocated to it to the use cases that entity serves.
