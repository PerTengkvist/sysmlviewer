# UseCaseTraceabilityView

Requirement traceability of the driving use cases. Each case points with «objective» to the requirement it must fulfil (right) and with «refine» to the user story it refines (left). One expose names the driving use cases; one expose per requirement (in another file) adds exactly the requirements they trace to. The filter keeps use cases, requirements and dependencies, so actors and «include» are left out.
