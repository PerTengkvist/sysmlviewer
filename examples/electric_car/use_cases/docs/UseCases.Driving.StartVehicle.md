# StartVehicle

The driver presses the start button with the brake held. The car authenticates the key, releases the immobilizer, closes the high-voltage contactor and shows Ready. Starting is where the immobilizer requirement is met: the car becomes Ready only once the key has been approved.

## Relations

- Refined by `Security`.
- Pursues requirement `PowerModes`.
- Pursues requirement `Immobilizer`.
- Included by `Drive`.
- Refines `DriveToDestination`.
