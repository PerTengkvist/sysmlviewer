# Requirements

Stakeholder requirements and user stories for a compact battery-electric passenger car. Size, performance, safety, security and comfort are the requirement groups. Driving, charging and parking are told as user stories. Leaf requirements refine a group. A leaf is traced to the logical parts along the function chain: a use case pursues it as objective, a functional entity refines that use case, and the entity is allocated to a logical part. A satisfy from a logical part to a leaf is kept only where the chain does not reach that part, such as the body for the size and crash requirements, or the brake pedal for braking distance, which the chain already traces to the drive controller and the friction brakes.
