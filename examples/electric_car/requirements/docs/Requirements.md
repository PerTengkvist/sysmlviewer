# Requirements

Stakeholder requirements and user stories for a compact battery-electric passenger car. Size, performance, safety, security and comfort are the requirement groups. Driving, charging and parking are told as user stories. Leaf requirements refine a group. A leaf is traced to the logical parts along the function chain: a use case pursues it as objective, a function refines that use case, and the function's entities are allocated to logical parts. A logical part satisfies a leaf directly only where that chain does not reach it, such as the body for size and crash requirements or the brake pedal for braking distance.
