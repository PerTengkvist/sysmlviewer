# storage_ssi

Logical **interface** (port definition) in package `LogicalPorts`.

## Classification

| Property | Value |
|----------|-------|
| Kind | storage |
| Domain | storage |

## Description

Storage service interface. Follows S/U naming: `*_s?i` interface type, `*_s?p` provided port, `*_r?p` required port on consuming parts.

## Usage

Referenced as the type of ports on `storage` parts and as connection interface names in logical wiring.
