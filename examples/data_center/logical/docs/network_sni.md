# network_sni

Logical **interface** (port definition) in package `LogicalPorts`.

## Classification

| Property | Value |
|----------|-------|
| Kind | network |
| Domain | network |

## Description

Network service interface. Follows S/U naming: `*_s?i` interface type, `*_s?p` provided port, `*_r?p` required port on consuming parts.

## Usage

Referenced as the type of ports on `network` parts and as connection interface names in logical wiring.
