# monitoring_sai

Logical **interface** (port definition) in package `LogicalPorts`.

## Classification

| Property | Value |
|----------|-------|
| Kind | API |
| Domain | monitoring |

## Description

Monitoring API interface. Follows S/U naming: `*_s?i` interface type, `*_s?p` provided port, `*_r?p` required port on consuming parts.

## Usage

Referenced as the type of ports on `monitoring` parts and as connection interface names in logical wiring.
