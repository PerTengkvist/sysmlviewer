# orchestrator_sai

Logical **interface** (port definition) in package `LogicalPorts`.

## Classification

| Property | Value |
|----------|-------|
| Kind | API |
| Domain | orchestrator |

## Description

Northbound orchestrator API type. Follows S/U naming: `*_s?i` interface type, `*_s?p` provided port, `*_r?p` required port on consuming parts.

## Usage

Referenced as the type of ports on `orchestrator` parts and as connection interface names in logical wiring.
