# compute_smi

Logical **interface** (port definition) in package `LogicalPorts`.

## Classification

| Property | Value |
|----------|-------|
| Kind | metrics |
| Domain | compute |

## Description

Compute metrics interface. Follows S/U naming: `*_s?i` interface type, `*_s?p` provided port, `*_r?p` required port on consuming parts.

## Usage

Referenced as the type of ports on `compute` parts and as connection interface names in logical wiring.
